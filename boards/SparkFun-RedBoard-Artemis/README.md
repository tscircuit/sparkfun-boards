# SparkFun RedBoard Artemis

An Arduino Uno-compatible development board built around the SparkFun Artemis
module (Apollo3 Blue), with USB-C, Qwiic, a Cortex Debug (SWD) header, and
CR2032 battery backup.

For more information about this board, visit the official SparkFun product page:

[https://www.sparkfun.com/sparkfun-redboard-artemis.html](https://www.sparkfun.com/sparkfun-redboard-artemis.html)
